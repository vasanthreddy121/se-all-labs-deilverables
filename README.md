# Software Engineering Lab Deliverables

This repository contains my Software Engineering lab assignments, source code, documentation, reports, and demonstration evidence completed as part of my coursework at PES University.

## Repository Structure

| Lab | Topic | Contents |
|---|---|---|
| Lab 1 | Lab 1 Deliverables | Assignment files and related documentation |
| Lab 2 | Agile Project Management with Jira | Sprints, user stories, story points, and project management evidence |
| Lab 3 | Software Architecture Selection | UML component diagram and architectural justification |
| Lab 4 | VibeCoding | Fruit Catcher game, before/after demonstration videos, and LLM conversation history |
| Lab 5 | Static Code Analysis | Auction-bidding application, testing, code analysis reports, issue documentation, and reflections |
| Additional Labs | Other Software Engineering Labs | Organized assignment files and supporting materials, where applicable |

*The exact contents of each folder depend on the files included in the corresponding lab submission.*

## Technologies and Tools

- **Project Management:** Jira, Agile, Scrum
- **Software Architecture:** UML component diagrams, Microservices Architecture
- **Programming:** Python
- **Game Development:** Pygame
- **Static Code Analysis:** Pylint, Flake8, Bandit
- **Testing:** Python `unittest`
- **Version Control:** Git and GitHub

## Purpose

The purpose of this repository is to maintain a structured collection of Software Engineering lab deliverables, including implementation files, documentation, testing evidence, and project demonstrations.

## How to Use

1. Open the folder for the required lab.
2. Read the assignment documentation and README files provided within that folder.
3. Follow the relevant setup and execution instructions.
4. Refer to the included reports, screenshots, and demonstration videos where applicable.

## Notes

- Each lab is maintained in a separate folder for easier navigation.
- Some assignments may require additional dependencies, datasets, or configuration.
- Refer to the individual lab documentation for specific requirements and execution instructions.
- This repository is intended for academic reference and coursework organization.
